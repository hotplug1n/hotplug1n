## `$ whoami`

Sou desenvolvedor **Fullstack** com foco em construir aplicações modernas, escaláveis e seguras.

Meu diferencial é unir **engenharia de software + cibersegurança** desde o início do desenvolvimento.

Não penso apenas em:

```text
"Como faço essa feature funcionar?"
```

Também penso em:

```text
"Como essa feature pode ser explorada?"
"Quais dados ela expõe?"
"Onde estão os trust boundaries?"
"Como posso quebrá-la antes que alguém faça isso?"
```

Minha filosofia:

> **Deliver fast. Build clean. Ship secure.**

Acredito em **Shift-Left Security**, **Secure SDLC** e **DevSecOps**, colocando segurança dentro do processo de desenvolvimento em vez de tratá-la como uma etapa final.
